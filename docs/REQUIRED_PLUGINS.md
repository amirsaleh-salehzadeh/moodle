**Audit date:** 27 October 2026  
**Environment:** local Moodle 5.3+ (branch 503; core build 20261021), database inventory read from the configured local development database. This is not a production installation recommendation.

## Installation and configuration record

- No new plugin was installed in response to the installation request because every uninstalled candidate lacked a verified compatible Moodle 5.3 release or had a current maintenance concern. Attendance and Custom certificate were already present in both the code tree and Moodle's installed component records.
- The installed optional plugin code is under `public/mod/attendance` and `public/mod/customcert`; certificate elements are under `public/mod/customcertelement`.
- The checkout's project notes record the local CLI upgrade as completed on 27 October 2026. Activity setup, access-control verification, and actual learner/lecturer use remain unverified.
- No production database/file backup or production change was performed. Before any future installation, take and verify backups of both database and `moodledata`, check the exact official release against branch 503, inspect dependencies/security notices, install in a development clone, run Moodle's supported upgrade, purge caches, run cron, configure capabilities and verify workflows.
- For Attendance, create an approved course activity, define sessions/statuses, grant only appropriate course staff attendance management, and test marking, learner visibility, reports and exports.
- For Custom certificate, approve template/branding and eligibility criteria, create an activity, restrict issue/verification capabilities, then test generation and learner download.
- Optional releases with explicit 5.3 Marketplace metadata (`mod_checklist` 4.1.0.9, `block_teacher_checklist` 1.3.3, and `format_flexsections` 5.0.5) are compatible candidates only; package downloads were blocked by the browser's download authority gate, so they remain uninstalled pending an authorized download path and local functional review.

## Evidence limits

The local plugin inventory establishes installed component versions, not security posture or functional acceptance. Official Moodle plugin listings and forums were rechecked on 27 October 2026. Completion Progress lists support through Moodle 5.1 only; the Custom SQL listing does not reach 5.3; Configurable Reports has no 5.3 declaration in the official listing and its forum has unresolved 5.x install/maintenance discussions; Questionnaire's listing does not establish 5.3 compatibility; Tiles has a current discussion reporting that it is no longer maintained. The five plugins named above therefore remain **not installed**. Recheck official releases if maintainers publish supported 5.3-compatible versions.
