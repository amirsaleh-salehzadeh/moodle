# Eastern Cape theme navigation feature support

**Reviewed:** 27 October 2026  
**Scope:** `public/theme/echealth` and the current local Moodle 5.3+ installation. The implementation follows the navigation and QA prompts in `ec-health-moodle-ui-kit/prompts/`.

## Implemented

- The authenticated sidebar provides Dashboard, Site home, My Courses, Course Catalogue and Calendar. Announcements and Certificates are conditional on an available, viewable destination. Anonymous navigation continues to use Moodle/Boost navigation.
- Management destinations are capability and route checked. A single expandable Administration group includes available user, course, cohort/campus, competency, report and site-administration links, with relevant administration sublinks for site admins. Course management respects category-scoped permissions and the create-course action points to a category the user can manage.
- Course navigation is contextual: Assignments, Quizzes, Grades, Question Bank and Enrolments appear for the current course when the matching capability is granted. Attendance appears only when an installed attendance activity is accessible. Expandable navigation remembers its state, opens groups containing the active destination and supports keyboard interaction.
- The dashboard renders capability-based student, lecturer and site-administrator views. Students see their enrolled courses, progress, completions, upcoming events and announcements, with visible catalogue discovery when they have no enrolments. Lecturers see teaching courses without misleading personal progress bars, pending grading counted through the Assignment API, and a Review grading action when they can grade. Site administrators see live active-account and visible-course totals with capability-filtered management actions. Coordinator copy and permissions remain supported. All views use Moodle records; catalogue discovery cards do not imply enrolment or progress.
- Completion totals count only the signed-in user's enrolled courses with completion tracking enabled. Course cards use Moodle's completion-progress API. Where course grades are visible and the user has the matching grade-report capability, the dashboard shows that user's final course grade and links to Moodle's own grade report. The sidebar links to the user's Moodle badges; the dashboard displays actual earned badges and issue dates. Site admins with badge-management access also get a badge administration link.
- Calendar shows up to five upcoming live Moodle events across site, course, group and personal calendars, including when the user has no course enrolments. Event links open the matching calendar day. Announcements aggregate recent, visible site and enrolled-course news-forum discussions. The dashboard also shows the current user's unread Moodle notification count and links to the native inbox and notification preferences; Moodle's header notification popover remains in place.
- Dashboard quick actions are capability filtered. The theme hides the legacy Navigation and Administration/Settings blocks on the dashboard only, leaving native blocks available elsewhere.
- The supplied brand assets and design are integrated into the Boost child theme: departmental masthead and logo, multicolour stripe, hero illustration, relevant SVG icons, theme tokens and responsive course-card styling. Course images stored in Moodle take precedence over matching sample WebP fallbacks.
- The mobile drawer supports Escape, contained tab navigation and outside-focus redirection; Boost manages focus restoration and backdrop behavior. Moodle core and native course/catalogue pages remain unchanged.

## Conditional features and installation state

- Moodle-compatible Attendance (`mod_attendance`) and Custom certificate (`mod_customcert`) are installed in the local Moodle 5.3 site. The Custom certificate element plugins were installed with the module. The selected plugin source branches are `MOODLE_503_STABLE`; Moodle's CLI upgrade completed successfully, no upgrade remains pending, caches were purged and maintenance mode was disabled.
- Plugin installation makes the activity types available; it does not create course activities or issue certificates. There are no configured Attendance or Custom certificate activities in the demo courses yet, so the theme correctly keeps those activity links hidden until an activity is added and the current user has view permission. The optional certificate destination uses one eligible activity to avoid duplicate top-level links.
- Course enrolment and grade destinations are course-scoped and permission checked. The course list is bounded to keep navigation manageable.
- The dashboard reflects the signed-in account's live records. Empty counts and empty states are expected when Moodle has no matching data; no sample enrolments, grades, completion records or events are invented by the theme.
- Core badges and course badges are enabled in this site, but there are currently no badge definitions or awards. Grade items exist, but there are no grade values or course completion records. The new views therefore show no invented grades, progress completions, or awards.
- Sample course imagery is demonstration art and appears only when a visible course title matches a configured fallback. It is not departmental photography.
- This work adds Moodle entry points to existing capabilities. It does not create a global user directory, enrolment wizard, campus/SIS subsystem, cross-course assessment queue, analytics/export centre or new reporting backend.
