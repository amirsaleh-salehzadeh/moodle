# Feature and proposal compliance matrix

**Audit date:** 26 October 2026. **Purpose:** evidence-based Moodle capability mapping. **Proposal source:** not present in accessible repository materials or attachments for this audit. Requirement group labels below are planning categories, not quoted or verified Eastern Cape procurement clauses. **Implementation update:** 27 October 2026. The theme now renders capability-based learner, lecturer and administrator dashboards, visible own course final grades, scoped completion counts/progress, and earned Moodle badges where configured, plus upcoming Moodle calendar events, recent site/course announcement-forum discussions, and the signed-in user's unread notification count with native inbox/preferences links. Attendance and Custom certificate plus element plugins are installed on compatible Moodle 5.3 branches. Role-specific acceptance, populated grade/completion/badge/calendar/announcement scenarios, and notification delivery configuration remain unverified.

## Status key

- **Native Moodle:** core capability exists; configuration or records are not implied.
- **Configured Moodle:** a Moodle setting/record is evidenced; workflow still may need testing.
- **Compatible plugin:** requires a separately selected, version-compatible plugin.
- **Partially supported:** some native capabilities exist but scope/workflow is missing.
- **Requires custom development:** integration/reporting beyond configured core capabilities.
- **Outside demo scope:** enterprise function not represented by this LMS proof of concept.

Current status vocabulary: Verified present (record/config only), Partial, Not evidenced, Blocked (proposal unavailable), Needs verification.
